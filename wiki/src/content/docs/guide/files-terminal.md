title: 项目文件与终端

---

「项目文件管理」页把两个不同视角的文件系统放在同一个界面里，适合改代码、查配置、临时排障。

## 双通道视角

| `target` | 操作对象 | 适用场景 |
|---|---|---|
| `source` | 宿主源码目录 `workspace/{app_id}/src` | 修改下次构建要用的源码 |
| `container` | 运行中容器的文件系统 | 查看运行态配置、临时改文件排障 |

:::note[两者互不影响]
改 `source` 不会自动同步进容器；改 `container` 里的文件也不会回写源码目录。
构建使用的始终是 `source`。
:::

## 支持的操作

| 操作 | 说明 |
|---|---|
| 浏览目录 | 列表展示文件 / 目录，可切换通道 |
| 读取文件 | 文本文件在线查看 |
| 在线编辑保存 | 文本文件直接保存 |
| 上传 | 支持多选 |
| 下载 | 单文件，或整目录打包为 zip |
| 新建目录 | 目录级操作 |
| 重命名 | 文件与目录均可 |
| 删除 | 文件与目录均可 |

## 安全与上限

所有路径都经 `safe_join` 校验，**拒绝绝对路径与 `..`**，防止越出应用工作目录。

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `FILE_MAX_READ_KB` | `512` | 在线预览 / 编辑的文本体积上限，超出只能下载 |
| `FILE_MAX_UPLOAD_MB` | `50` | 单文件上传上限 |
| `FILE_MAX_ARCHIVE_MB` | `200` | 整目录打包下载上限 |

## 容器 Web 终端

基于 WebSocket + `docker exec` 的交互式 TTY，可以在浏览器里直接进容器执行命令。

### 两个入口

- 应用详情抽屉 → 「终端」tab
- 「项目文件管理」页 → 终端卡片

### 全局单会话互斥

:::caution[同一时间只允许一个容器终端会话]
平台对终端会话做了**全局互斥**，避免同一容器上挂多个 `exec` 进程。
要开另一个入口的终端，需先断开当前会话。
:::

离开「项目文件管理」页会自动断开该页的终端会话；抽屉内的终端行为不变。

### 终端连不上时

按顺序检查：

1. 目标应用的容器是否处于 `running` 状态；
2. 链路中的 nginx 是否配置了 WebSocket 升级头（见[域名与双层 Nginx](/deploy/nginx/)）；
3. 是否已有另一个终端会话占用（全局单会话互斥）；
4. 浏览器控制台是否有 WebSocket 连接被拒的报错。

:::note[容器内可能没有 ps]
部分基础镜像（如 nginx 官方镜像）不包含 `ps`。排查残留进程时需考虑这个限制，
可改用 `ls /proc` 等方式观察。
:::

## 相关接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/apps/{app_id}/files` | 浏览目录（`target=source\|container`） |
| GET / PUT | `/api/apps/{app_id}/files/content` | 读取 / 保存文本文件 |
| POST | `/api/apps/{app_id}/files/upload` | 上传文件（多选） |
| POST | `/api/apps/{app_id}/files` | 新建 / 重命名 / 删除（`op=mkdir\|rename\|delete`） |
| GET | `/api/apps/{app_id}/files/download` | 下载文件或目录打包 zip |
| WS | `/ws/apps/{app_id}/shell` | 容器 Web 终端 |
