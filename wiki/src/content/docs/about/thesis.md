PocketPaaS 为个人毕业设计作品，主题是「在单机 Docker 之上构建轻量类 PaaS 平台」的完整交付链路。
本页是设计说明书与论文的要点摘要，完整内容见仓库 `最终版本文档/` 下的原始文档。

## 设计目标

| 目标 | 落地方式 |
|---|---|
| 降低交付门槛 | 源码（zip / Git / 示例包）进入后自动完成类型识别、Dockerfile 生成、构建、部署 |
| 单机可跑通全链路 | 复用宿主 Docker 引擎（`docker.sock`），不依赖集群编排 |
| 控制面轻量 | 单个 FastAPI 进程，与业务容器共存于同一台机器 |
| 本地到线上零改动迁移 | `DEPLOY_MODE` 双模式开关（`local` / `prod`） |
| 可观测与可运维 | 指标采样、就绪探针、自愈、告警、审计、一键诊断、Web 终端 |

## 架构与设计要点

- **四层结构**：外层 Nginx（宝塔）→ 平台内层 Nginx → 控制面（FastAPI + SPA）→ 数据面（应用容器）。
- **控制面 / 数据面分离**：控制面不承载业务流量，只通过 `docker.sock` 管理宿主容器；
  数据面容器接入专用隔离网桥，容器间互通关闭。
- **双模式设计**：`local` 走宿主端口直连，`prod` 走泛域名 + 动态反向代理。
- **数据库设计**：9 张表覆盖应用、部署、路由、构建日志、指标、用户、会话、告警与审计。
- **接口设计**：REST + WebSocket，按系统、认证、用户、应用、文件、诊断、Webhook、审计、告警分模块。

## 关键实现

| 主题 | 要点 |
|---|---|
| 容器运行时管理 | 部署 / 停止 / 重启 / 销毁，状态与数据库保持一致 |
| 资源隔离 | cgroup v2 限制 CPU 与内存，内存为硬约束 |
| 端口分配 | 区间内原子分配，针对 TOCTOU 竞态做了修复与重试 |
| 镜像构建 | 按项目类型生成 Dockerfile，构建日志分行落库 |
| 动态路由 | 渲染 server 块 → `nginx -t` 校验 → `nginx -s reload` 热载 |
| 安全加固 | 7 项容器加固、危险 Dockerfile 指令拦截、Git 私网 SSRF 防护 |
| 鉴权 | PBKDF2 加盐哈希、HttpOnly 会话、自绘 SVG 图形验证码 |
| 稳定性 | 失败残留清理、就绪探针四态、自愈重启、路由同步降级 |

## 测试与结果

### 测试范围

- **功能测试**：全链路功能与新增能力（文件管理、终端、诊断、自动部署、就绪探针、告警、审计、用户权限）的端到端 / 定性验证。
- **安全测试**：输入校验、SSRF 防护、容器加固、Webhook 签名校验。
- **资源隔离测试**：CPU 配额、内存上限、网络隔离。
- **稳定性测试**：并发部署、失败清理、探针与自愈。
- **性能测试**：控制面与数据面分别压测（20 线程 × 10 请求）。

### 关键数据

| 指标 | 结果 |
|---|---|
| 控制面吞吐 | **155.6 QPS** |
| 数据面吞吐 | **1403.5 QPS** |
| 容器加固项 | **7 项全部生效** |
| CPU 配额 | 精确生效 |
| 内存上限 | 硬约束，应用之间互不影响 |
| 网络隔离 | 容器间默认不可互通 |

:::note[测试中发现并修复的问题]
并发部署测试（4 个应用同时部署）暴露了端口分配竞态：2 个请求返回 500 且状态卡在 `building`。
该缺陷已通过原子分配与状态收尾修复，并纳入稳定性验证。
:::

### 测试结论

1. **功能正确性**：全链路功能通过端到端验证，新增的运维与可观测能力亦通过验证。
2. **安全有效性**：恶意输入被正确拒绝；Webhook 错误签名被拒绝；容器加固全部生效。
3. **隔离有效性**：CPU 配额精确、内存为硬约束且互不影响、容器间默认不互通。
4. **稳定性**：失败清理与状态标记、就绪探针与自愈巡检工作正常；并发竞态缺陷已修复。
5. **可观测性**：一键诊断输出结构化结论，告警可确认并自动恢复，审计完整留痕。
6. **性能**：控制面 155.6 QPS、数据面 1403.5 QPS，满足轻量级单机场景需求。

## 不足与展望

| 不足 | 后续方向 |
|---|---|
| 单节点实现，不支持多节点调度与集群化 | 引入 Swarm 或轻量调度层，实现跨节点部署 |
| 配额粒度仅 CPU / 内存 | 增加磁盘 IO、网络带宽限制与总配额池管理 |
| 镜像构建效率有限 | 引入构建缓存复用、多阶段构建、私有镜像仓库集成 |
| 未启用自动 HTTPS | 泛域名证书 + DNS-01 签发，由外层 Nginx 终止 TLS |
